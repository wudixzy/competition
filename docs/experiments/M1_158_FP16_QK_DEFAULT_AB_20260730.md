merge, shapes, tensors, seeds, A/B ordering, and gates are identical to

Every value was finite. LSE relative L2 remained `3.25e-8` to `3.66e-8`,
and output max absolute error remained `1.526e-5` to `6.104e-5`. The output
relative-L2 values are identical to M1-157 and exceed the frozen `1e-5`

The median speedup was 1.166x and the minimum was 1.154x. This also matches
M1-157 within ordinary timing variation.

## Decision

The selector change did not alter the numerical output and did not produce a
meaningfully different performance path. CoreX therefore appears to dispatch
both selectors to the same implementation for this fixed type and shape.

The FP16-input QK direction is closed. Do not scan numbered cuBLAS algorithms,
tile sizes, or relaxed tolerances. The retained positive evidence is that
QK data flow has a 15%-17% operator-level opportunity. The next structural
candidate must preserve the qualified FP32 QK/PV arithmetic while avoiding
full score materialization or repeated score traffic; it starts again at the
component numerical gate.

All lifecycle, scoped cleanup, postflight, repeated preflight, memory
comparison, and fatal scans passed. Privacy-safe evidence is under
`docs/experiments/evidence/M1_158_FP16_QK_DEFAULT_AB_20260730`.
